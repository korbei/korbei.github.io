Code Formatter↗ open toolThird-party

Format and beautify JSON, YAML, TOML, XML, HTML, and CSS — with JSON/CSS minify and JSON schema validation.

$ prettier -w file.js

JS/TS/CSS/HTML/JSON/Markdown

$ black file.py

Python

$ gofmt -w file.go

Go

$ jq . file.json

Pretty-print JSON

ⓘ Each language brings its own formatter — prettier via npm, black via pip, gofmt with the Go toolchain. Only jq (for JSON) is in the distro repos; the browser tool covers them all in one place.

Needsnpm: prettierpip: blackgo toolchainjq

Data Diff↗ open toolIn distro repos

Compare two JSON, YAML, or TOML documents by structure, not text: added, removed, and changed values with their paths. Key order and formatting are ignored. Runs in your browser.

$ diff <(jq -S . a.json) <(jq -S . b.json)

Structural JSON diff (keys sorted)

$ dyff between a.yaml b.yaml

Readable YAML/JSON diff (dyff — Homebrew/AUR/Go)

⛓ Chain it

$ diff <(curl -s host-a/config.json | jq -S .) <(curl -s host-b/config.json | jq -S .)

Diff the same JSON on two servers

Needsjq

HAR Viewer↗ open toolThird-party

Open a .har network export and explore its requests, sizes, status codes, and a timing waterfall — entirely in your browser. Nothing is uploaded.

$ jq '.log.entries[] | {url: .request.url, status: .response.status}' session.har

List requests + status

$ jq '[.log.entries[].time] | add' session.har

Total load time (ms)

ⓘ jq reads the .har JSON, but there is no built-in waterfall/timeline view.

Needsjq

JSON ↔ YAML ↔ TOML↗ open toolThird-party

Convert structured data between JSON, YAML, and TOML, live in your browser.

$ yq -p json -o yaml file.json

JSON → YAML

$ yq -p yaml -o toml file.yaml

YAML → TOML

$ yq -p toml -o json file.toml

TOML → JSON

ⓘ These use mikefarah’s yq (a Go binary from its GitHub releases); the yq some distros package is a different, jq-based tool. dasel (in the Debian/Ubuntu repos) is an in-repo alternative.

Needsyq (mikefarah)

JSON to SQL↗ open toolThird-party

Infer a SQL CREATE TABLE from a JSON sample or a JSON Schema — column types, nullability, and a primary-key guess — for PostgreSQL, MySQL, or SQLite. Runs in your browser.

From JSON: flatten to CSV first

JWT Debugger↗ open toolThird-party

Decode and inspect JSON Web Tokens: view the header and payload, check expiry, and verify HS/RS/PS/ES signatures — all in your browser.

$ awk -F. '{print $2}' <<< "$JWT" | base64 -d 2>/dev/null | jq

Decode the payload

$ step crypto jwt verify --key pub.pem < token.jwt

Verify the signature

⛓ Chain it

$ for i in 1 2; do awk -F. -v n=$i '{print $n}' <<< "$JWT" | base64 -d 2>/dev/null | jq; done

ⓘ JWTs are base64url; the quick decode may need padding. `step` (from smallstep.com — not in most distro repos) verifies signatures properly.

Needsjqstep (smallstep.com)

URL Inspector↗ open toolIn distro repos

Break a URL into its parts and an editable query-string table, then rebuild it. Decodes parameters and exports them as JSON. Runs in your browser.

$ trurl --url "https://a.com/p?q=1" --get '{host} {path} {query}'

Getting the packages

Everything here is free and open source. Package names shown are Debian/Ubuntu; Fedora and Arch package the same tools under different names (e.g. exiftool is libimage-exiftool-perl on Debian but perl-Image-ExifTool on Fedora/Arch). Tags like npm:, pip:, or cargo: install through that ecosystem rather than your distro.

$ sudo apt install jq imagemagick libimage-exiftool-perl qrencode zbar-tools tesseract-ocr poppler-utils

Prefer not to install anything? Every one of these has a browser version here that runs with nothing to set up.
