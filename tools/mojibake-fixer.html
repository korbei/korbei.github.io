Mojibake is text that has been decoded with the wrong character set — most often UTF-8 bytes read as Windows-1252, which turns “café” into “cafÃ©”, “’” into “â€™”, and “€” into “â‚¬”. This tool reverses that mistake and gives you the original text back.

It works by re-encoding each character to its Windows-1252 byte and decoding those bytes as UTF-8 — the exact inverse of how the text got garbled. Crucially, if the text is already valid (or the reinterpretation would not produce valid UTF-8), it is left untouched, so correctly-encoded text is never damaged. Double-encoded text is repaired by applying the fix more than once.

Everything runs in your browser; the text you paste never leaves your device.

Frequently asked questions

What is mojibake?+

It’s the garbled text you get when bytes are decoded with the wrong character encoding — classically UTF-8 data interpreted as Windows-1252 or Latin-1. The tell-tale signs are sequences like “Ã©”, “â€™”, and “â‚¬”.

Will it damage text that is already correct?+

No. The repair is only applied when reinterpreting the text yields valid UTF-8; otherwise the input is returned unchanged. Correctly-encoded accented text (café, naïve, 日本語) is left exactly as-is.

It didn’t fix my text — why?+

This tool targets the most common case (UTF-8 misread as Windows-1252/Latin-1). Text garbled a different way — a different source encoding, or bytes already lost during a lossy conversion — can’t always be recovered.

Is my text uploaded anywhere?+

No. The repair runs entirely in your browser with client-side JavaScript; your text never leaves your device.
