About the Markdown Editor

  • 👁️Live GitHub-flavored preview
  • 🧭Table of contents & scroll sync
  • 🏷️Front-matter panel & paste HTML → Markdown
  • 📤Export to Markdown or HTML
  • 🛡️Sanitized preview, images blocked by default
  • ⚡Instant results
  • 🔒100% private — runs in your browser
  • 🆓Free, no sign-up

The Markdown Editor is a split-screen editor with an instant, GitHub-flavored preview that renders as you type. It is 100% client-side: your document is never uploaded, so it is safe for release notes, internal docs, meeting notes, or anything you would not paste into an online tool.

It supports GitHub Flavored Markdown — headings, bold and italic, lists and task lists, tables, blockquotes, fenced code, strikethrough, and autolinks. A table of contents is built from your headings and stays in sync as you write, and the editor and preview scroll together so you never lose your place. A formatting toolbar wraps the current selection, and your draft is saved in your browser so it survives a reload.

It also detects YAML front matter — the leading --- block used by Jekyll, Hugo, and Astro — and shows it in its own panel, out of the preview and word count. You can convert HTML on your clipboard to clean Markdown with one click, and fenced code blocks are syntax-highlighted in the preview.

When you are done, copy the Markdown, copy the rendered HTML, copy rich text to paste straight into a document or email, or download a self-contained HTML file. The preview is always sanitized, and images from external URLs are blocked by default so nothing loads from the network unless you allow it.

How to use it

  1. 1Type or paste Markdown on the left; the preview on the right updates instantly.
  2. 2Use the toolbar to format the selection, and the Contents panel to jump between headings.
  3. 3Toggle “Sync scroll” to keep the editor and preview aligned, or “Remote images” to load external images.
  4. 4Copy the Markdown, HTML, or rich text, or download a standalone .md or .html file.

Frequently asked questions

Is my document uploaded anywhere?+

No. Everything — editing, preview rendering, and export — happens in your browser. There is no server and no upload, and your draft is stored only in your own browser’s local storage.

Which Markdown flavor does it use?+

GitHub Flavored Markdown (GFM): standard Markdown plus tables, task lists, strikethrough, and autolinks. Raw HTML in your Markdown is rendered but sanitized first.

Is the preview safe from malicious HTML?+

Yes. The rendered HTML is always passed through DOMPurify before it is shown, so scripts and event handlers are stripped. Links open in a new tab with no referrer, and images from external URLs are blocked until you opt in.

Why are some images not showing?+

Images loaded from external (http/https) URLs are blocked by default so the preview makes no network requests. Enable “Remote images” to load them; images embedded as data URIs always render.

Can I get the HTML out?+

Yes. You can copy the rendered HTML, copy rich text to paste directly into a document or email, or download a standalone HTML file with its styling included.

Does it handle front matter and pasted HTML?+

Yes. A leading YAML front-matter block (the --- section used by static-site generators) is parsed and shown in its own panel, kept out of the preview and word count. And “Paste HTML → MD” converts rich HTML on your clipboard — from a web page, doc, or email — into clean GitHub-flavored Markdown at the cursor.
