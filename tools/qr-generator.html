A QR code is a two-dimensional barcode that stores text a camera can read instantly. What you encode is just a string — but the format of that string decides what a phone does when it scans it. A plain URL opens a browser; a specially formatted string can join a Wi-Fi network, add a contact, start an email, drop a map pin, or create a calendar event without any typing.

This generator builds the correct string for each of those content types — URL, plain text, email (mailto), telephone (tel), SMS (SMSTO), geo coordinates, Wi-Fi, contact cards (vCard), and calendar events (iCalendar) — handling the escaping each format requires, and renders a scannable QR code live. Everything is generated in your browser, so the data you encode is never uploaded.

You can also pick the error-correction level. QR codes include redundant data so they still scan when partly dirty, damaged, or covered by a logo: Low (L) recovers about 7%, Medium (M) 15%, Quartile (Q) 25%, and High (H) 30%. Higher levels are more robust but make the code denser. Download the result as a PNG raster or a crisp, scalable SVG.

How to use it

  1. 1Choose a content type, then fill in its fields — the encoded string updates live and is shown under “Encoded content”.
  2. 2Pick an error-correction level (L/M/Q/H). Use H if the code will be printed small or overlaid with a logo.
  3. 3Optionally adjust the size, quiet-zone margin, and colors. Keep a dark foreground on a light background for reliable scanning.
  4. 4Scan the preview to test it, then download it as PNG (for documents and the web) or SVG (for print and scaling).

Content types & their encodings

Telephone / SMS
tel: dials a number; SMSTO: starts a text with an optional message.
Geo
geo:lat,lng drops a pin in the phone’s maps app.
Wi-Fi
WIFI:… lets a phone join a network (name, password, encryption) in one tap.
vCard
A contact card (name, phone, email, address) that adds straight to the address book.
Event
An iCalendar VEVENT (title, time, location) that adds to the calendar.

Error-correction levels

L — Low
Recovers ~7% damage. Smallest, densest-friendly code; use in clean conditions.
M — Medium
Recovers ~15%. A good general-purpose default.
Q — Quartile
Recovers ~25%. More robust for printed or busy backgrounds.
H — High
Recovers ~30%. Best when the code is small or has a logo over it.

Frequently asked questions

Do QR codes expire or need an internet connection to create?+

No. A QR code is a static encoding of whatever data you put in it — it never expires, and this generator builds it entirely in your browser with no server involved. The only time the internet matters is when someone scans a code whose content is a URL.

Which error-correction level should I use?+

Medium (M) is a solid default. Choose High (H) if the code will be printed small, displayed on a busy background, or have a logo placed over the center — the extra redundancy lets it still scan. Low (L) produces the least dense code and is fine for clean, on-screen use.

PNG or SVG — which download should I pick?+

Use SVG for print and anywhere the code may be resized, since it stays perfectly sharp at any scale. Use PNG for quick placement in documents, slides, or web pages where a fixed-size raster image is easier to drop in.

Can I change the colors?+

Yes, but keep strong contrast — a dark foreground on a light background. Scanners rely on that contrast, and light-on-dark (inverted) codes fail on many readers, so the tool warns you when the colors are risky.

Why did my content become “too large for a QR code”?+

QR codes have a maximum capacity that shrinks as the error-correction level rises. A long vCard or note at level H can exceed it. Lower the error-correction level or shorten the content and it will fit.
