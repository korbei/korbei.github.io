This tool generates realistic-looking fake data for testing, prototyping, and demos. Define a schema — a list of named fields, each with a type like full name, email, date, or number — choose how many rows you want, and export it as JSON, CSV, SQL INSERT statements, or XML. Everything is generated in your browser; nothing is uploaded.

Generation is seeded, so the same seed always produces the same data. That makes your fixtures reproducible — commit a seed and everyone gets identical rows — while “Regenerate” gives you a fresh random set whenever you want one.

You can build the schema by hand, start from a preset (User, Product, Order), or import a JSON Schema: its top-level properties are mapped to field types automatically (by format, then by name, then by base type), giving you an editable starting point.

How to use it

  1. 1Build a schema — add fields and pick a type each, or choose a preset — or switch to “Import JSON Schema” and paste one.
  2. 2Set the number of rows and the output format (JSON, CSV, SQL, or XML). For SQL, set the table name.
  3. 3Optionally set a seed for reproducible output, or press Regenerate for a new random set.
  4. 4Copy or download the result from the output editor’s toolbar.
  5. 5Use the “Send to…” buttons to pipe the output into the Types generator, JSONPath, or Data Converter (JSON) — or the XPath Tester (XML).

Frequently asked questions

Is the data random or reproducible?+

Both. A seed drives a deterministic generator, so the same seed always yields the same rows — great for reproducible test fixtures. Press Regenerate to pick a new random seed and get a fresh set.

JSON, CSV, SQL, or XML — which should I pick?+

JSON for APIs and JavaScript; CSV for spreadsheets and bulk import; SQL for seeding a database (INSERT statements, with a table name you set); XML when a system expects it. All four come from the same generated rows.

How does importing a JSON Schema work?+

The schema’s top-level properties become fields. Each type is inferred from its format (email, date-time, uuid, uri…), then a name heuristic (a property called “firstName” becomes a first name), then its base JSON type. Nested objects and arrays are skipped, since the output is flat rows. The result is fully editable afterward.

Is the fake data safe to use?+

It is randomly assembled from generic word lists and is not real personal data. Everything is generated locally in your browser and never leaves your device.

How many rows can I generate?+

Up to 1,000 per run, which keeps the in-browser editor responsive. For larger datasets, generate in batches (e.g. change the seed each time).
