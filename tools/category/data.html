🗂️Data & formats

Work with structured data end to end: prettify and validate JSON, convert between JSON, YAML, and TOML, diff two documents structurally, query with JSONPath or XPath, and generate type definitions or a SQL schema from a sample. Every tool runs entirely in your browser.

🧹

Code Formatter

Format and beautify JSON, YAML, TOML, XML, HTML, and CSS — with JSON/CSS minify and JSON schema validation.

◇ works well with JSON to Types

🆚

Data Diff

Compare two JSON, YAML, or TOML documents by structure, not text: added, removed, and changed values with their paths. Key order and formatting are ignored. Runs in your browser.

◇ works well with Code Formatter

🌐

HAR Viewer

Open a .har network export and explore its requests, sizes, status codes, and a timing waterfall — entirely in your browser. Nothing is uploaded.

◇ works well with URL Inspector

🔄

JSON ↔ YAML ↔ TOML

Convert structured data between JSON, YAML, and TOML, live in your browser.

◇ works well with JSON to Types

🛢️

JSON to SQL

Infer a SQL CREATE TABLE from a JSON sample or a JSON Schema — column types, nullability, and a primary-key guess — for PostgreSQL, MySQL, or SQLite. Runs in your browser.

◇ works well with JSON to Types

🧬

JSON to Types

Turn a JSON sample or a JSON Schema into TypeScript, Zod, Go structs, Python dataclasses, Kotlin data classes, or Java records/Lombok. Infers optional and nullable fields. Runs in your browser.

◇ works well with JSON to SQL

🔎

JSONPath Tester

Query JSON live with JSONPath — filter, slice, and recurse, and see each matched value with its path, all in your browser.

◇ works well with Code Formatter

🪵

Log & Trace Analyzer

Open a huge log file — JSON/NDJSON, logfmt, syslog, or Java/app-server text — and get instant time-range narrowing, faceting, a timeline, request tracing, and full-text search, entirely in your browser with nothing uploaded.

🧭

XPath Tester

Test XPath expressions against XML or HTML live — see matched nodes, their location paths, and string/number/boolean results, all in your browser.

◇ works well with Code Formatter
