🔄Converters

Convert between formats and representations: data formats, colors, CSS units, timestamps, and character encodings; compress and convert images between WebP, PNG, and JPEG (including iPhone HEIC photos); plus round-tripping between UML class diagrams and source code, and breaking a URL into its parts.

Code to UML

Turn TypeScript or Java source into a Mermaid class diagram — classes, interfaces, enums, fields, methods, inheritance, and interfaces — rendered live in your browser.

Color Converter

Convert colors between HEX, RGB, HSL, HSV, and OKLCH, with a picker, alpha, and a WCAG contrast checker — all in your browser.

◇ works well with CSS Unit Converter

CSS Unit Converter

Encoder / Decoder
