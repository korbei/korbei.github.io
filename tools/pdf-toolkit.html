About the PDF Toolkit

  • 🧩Merge, split & reorder
  • 🔄Rotate & delete pages
  • 🖼️Images → PDF, PDF → images
  • ⚡Instant results
  • 🔒100% private — runs in your browser
  • 🆓Free, no sign-up

The PDF Toolkit lets you reorganise PDF documents without uploading them anywhere. Drop in one or more PDFs — and images if you like — and every page appears as a thumbnail in a single grid. From there you can drag pages into a new order, select pages to rotate or delete, combine several files into one, or pull a range of pages out into a new document. When you are done, save the result as a PDF or export the pages as images.

Because a PDF is often a contract, a bank statement, a signed form, or a scanned ID, this is exactly the kind of file you should think twice about handing to a random website. Here nothing is uploaded: the file is read, edited, and re-saved entirely inside your browser tab using pdf-lib and pdf.js. There is no server to receive your document, so a private file stays private and the whole process is instant.

One visual page grid covers every common operation. Merging is just dropping in a second file; splitting or extracting is selecting the pages you want and saving; reordering is dragging; and turning a folder of photos into a PDF is dropping the images in. Each page can be rotated in 90° steps, which is handy for scans that came in sideways.

How to use it

  1. 1Drop your PDFs (and any images) onto the box, or click to choose them. Each page shows up as a thumbnail.
  2. 2Drag thumbnails to reorder them, and click pages to select them.
  3. 3Rotate or delete the selected pages, or use the per-page controls that appear when you hover a thumbnail.
  4. 4Add more files at any time to merge them in, or keep only the pages you want to split a document.
  5. 5Click “Save PDF” to download the assembled document, or export every page as PNG or JPEG images in a zip.

What each action does

Merge
Add several PDFs (or images) — their pages join the same grid and save as one document.
Split / extract
Delete the pages you don’t want, or select a range, then save just those pages.
Reorder
Drag any thumbnail to a new position; the saved PDF follows the grid order.
Rotate
Turn selected pages in 90° steps — the rotation is baked into the saved file.
Images → PDF
Dropped JPEG, PNG, WebP, or GIF images each become a page sized to the image.
PDF → images
Render every page to a PNG or JPEG and download them together as a zip.

Frequently asked questions

Are my PDFs uploaded to a server?+

No. Reading, editing, and re-saving all happen locally in your browser — there is no upload and no server involved. That makes it safe to reorganise sensitive documents like contracts, statements, or scanned IDs.

Can it reduce / compress the PDF file size?+

Not in a meaningful way. True PDF compression means re-encoding fonts, images, and content streams, which is not something a browser can do reliably, so this tool deliberately does not offer a misleading “compress” button. It focuses on organising pages. To shrink image-heavy pages, exporting them as JPEG images can help.

Can I turn photos or scans into a PDF?+

Yes. Drop image files (JPEG, PNG, WebP, or GIF) in alongside — or instead of — PDFs. Each image becomes one page sized to that image, and re-encoding them also strips any EXIF or GPS metadata the photos carried.

Can it unlock or remove a password from a PDF?+

It can open PDFs that only have owner/permission restrictions and let you edit them, but it cannot remove a password that is required just to open the file — you need to know that password and open it elsewhere first. This tool is for organising pages, not defeating encryption.

Why are thumbnails slow to appear on a big PDF?+

Each page is drawn on demand as you scroll, rather than all at once, so a very large document stays responsive instead of freezing the tab. Scroll to a page and its thumbnail renders within a moment.
