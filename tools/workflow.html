About the Workflow Builder

  • 🔗Chain tools into a pipeline
  • ⚡Runs live as you build
  • 🔒Runs in your browser
  • ⚡Instant results
  • 🔒100% private — runs in your browser
  • 🆓Free, no sign-up

Most tool sites make you copy output from one tool and paste it into the next. The Workflow Builder lets you assemble those steps into a single pipeline: pick an input, add transform steps, and each step feeds its output into the next automatically. It runs live — edit the input or reorder a step and the whole chain re-runs.

The available steps are pure, deterministic transforms: Base64 decode, mojibake repair, convert between JSON/YAML/TOML, format, and generate TypeScript (and other) types from JSON. A step that receives input it can’t handle shows an error right where it is, so you can see exactly where a chain breaks.

Everything runs client-side — your input and every intermediate result stay in your browser and are never uploaded.

How to use it

  1. 1Type or paste your starting input at the top.
  2. 2Add steps and pick a tool for each; set that step’s options.
  3. 3Reorder or remove steps — the pipeline re-runs instantly.
  4. 4Copy or download the final output; expand any step to inspect its intermediate result.

Frequently asked questions

Which tools can I chain?+

The first set of steps covers Base64 decode, mojibake repair, data conversion (JSON/YAML/TOML), formatting, and JSON-to-types generation. More transforms will be added over time.

What happens if a step gets input it can’t handle?+

That step reports an error in place and the pipeline stops there, so the earlier successful output is preserved and you can see exactly which step failed and why.

Is my data uploaded anywhere?+

No. Every step is a client-side transform. The input and all intermediate results stay in your browser — nothing is sent to a server.
