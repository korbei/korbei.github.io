About the Metadata Inspector

  • 📷Photo EXIF & GPS
  • 📄PDF & Office document properties
  • 🧼Download a cleaned copy
  • ⚡Instant results
  • 🔒100% private — runs in your browser
  • 🆓Free, no sign-up

The Metadata Inspector reveals the hidden information tucked inside a file. Drop in a photo to see its full EXIF record — camera make and model, exposure settings, timestamps, and any GPS coordinates (shown on a map). Drop in a document — PDF, Word, Excel, PowerPoint, OpenDocument, or EPUB — to see its properties: author, who last edited it, the company, the application used, and creation/modification dates.

This matters because files leak more than their visible content. A photo from a phone can embed the exact spot it was taken; a Word or PDF file records who wrote and edited it, and sometimes a local file path that exposes a username. This tool shows you exactly what is there, flags the privacy-sensitive parts, and lets you download a cleaned copy with the metadata removed.

Everything runs locally in your browser — the file is never uploaded. Photos are cleaned losslessly (the pixels are copied byte-for-byte; only metadata is dropped). Documents are re-saved with their metadata fields cleared. To clean many files at once, use the batch Metadata Stripper.

How to use it

  1. 1Drop an image or document onto the box, or click to choose one.
  2. 2Review the privacy check at the top, then expand the sections to see every field.
  3. 3For a photo with GPS, reveal the location on a map (map tiles load only when you ask).
  4. 4Click “Download without metadata” to save a cleaned copy of the file.

What it reads

Photos
EXIF (camera, lens, exposure), GPS coordinates, timestamps, and IPTC/XMP — in JPEG, PNG, WebP, GIF, HEIC, and TIFF.
PDF
The document Info dictionary and XMP: title, author, subject, keywords, creator, producer, and dates.
Office / OpenDocument
Author, last-modified-by, company, manager, template, dates, and edit statistics from docProps / meta.xml.
EPUB
Title, author, publisher, language, and dates from the package document.

Frequently asked questions

Is my file uploaded anywhere?+

No. Reading the metadata and creating the cleaned copy both happen locally in your browser — there is no server and no upload. It is safe for private photos and confidential documents.

What is the difference from the Metadata Stripper?+

The Inspector is for looking at one file in detail (and optionally cleaning it). The Metadata Stripper is for cleaning many images and documents at once and downloading them as a zip.

Does removing metadata change the file?+

Photos are cleaned losslessly — the pixels are copied byte-for-byte and only metadata is removed. Documents are re-saved: the content is preserved intact, but the file is rewritten, so its bytes and size change.

Can it read HEIC and TIFF photos?+

Yes, it reads their metadata (including GPS). Cleaning is available for JPEG, PNG, WebP, and GIF; HEIC and TIFF can be inspected but not stripped losslessly in the browser.

Why should I remove GPS or author data before sharing?+

GPS coordinates can reveal where you live or work, and author/company fields identify who made a file. Stripping them before you post or send a file is a simple, effective privacy step.
